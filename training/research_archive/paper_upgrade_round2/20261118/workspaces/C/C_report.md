# C 交付：训练期结构消融和公平训练

两项实验均按事前方案执行，所有候选与负结果完整保留。C1 使用35期训练期已发出的基础预测，固定18项消融；C2 在67期训练活动内部的32/44/56三个终点评价随后各4期，实际完成108次神经网络拟合。验证和测试答案均未进入本轮实现。C1 的结果没有用于改变 C2 的方法或参数。

预登记为 `preregistration.json` / `preregistration_v2.json`。v1 的查询输入SHA手抄截短，事前改用 hashlib 计算并保留 v1，见 `pre_numeric_amendments.json`。PI 运行前审查补上文本类型、逐期预测封存和评分前源数据核验，候选与参数保持预登记版本。修补前的 `runs/*_001` 仅完成 prepare，保留归档；实际结果位于 `runs/c1_002`、`runs/c2_002` 及各自的 `_scores`。

## C1：收益取决于替换哪条线

末10期时间外推诊断的活动等权 MAPE（%，越低越好）如下。全19线共有3167案例；两线子面板有352案例。两者共享同一逐案例预测，均为10个活动。

|固定方法|全19线|T1000/T2000|两线相对独立差值（百分点）|
|---|---:|---:|---:|
|未校正|6.517472|6.744291|+0.826585|
|独立EWMA|6.095607|5.917707|0|
|原锚点差异，两线均替换|6.147986|6.388468|+0.470761|
|保留T2000独立，仅替换T1000|6.153644|6.439439|+0.521732|
|保留T1000独立，仅替换T2000锚点|6.089948|5.866735|−0.050971|
|以T1000为锚，仅替换目标T2000|6.166029|6.551149|+0.633442|

原配方对两条线的作用方向不同。T1000 的 MAPE 从独立7.287822变为8.331286；T2000 从4.547591变为4.445649。以T1000为锚后替换T2000，后者升至5.814476。仅替换T2000锚点的0.050971百分点收益属于固定消融结果，本轮没有据此产生新的优选方法。

完整18项结果见 `evidence_001/C1_last10_all_ablations.csv`，所有35期的逐活动配对差见 `C1_paired_event_differences.csv`。前15期、次10期、末10期分别保留在独立评分文件，未合并成新的“选择验证”。

α/收缩的消融表明，统一α后两线 MAPE 为5.944317，仅把差异α改为.3时为5.923393；统一收缩为6.321073，去除全部收缩为6.553797。这些固定对照显示原快差异滤波与结果变化相关。每个配方仍含其他共同项，结论限于本次配方和队列。

相同滤波/相同成对支持的两个实现最大最终分数差为7.45×10⁻⁹，与浮点舍入相符；相同支持的独立实现与通常独立输出完全相同。实际数据中锚点支持数与成对支持数始终相同，完整支持消融与原配方输出也完全相同。因此该消融在真实数据里没有改变支持池；缺线情况下的代数和回退行为由 fixture 单独检查。

## C1：校正均值和跨期波动分别报告

独立与原配方均减小了T1000部分阶段的平均残差绝对值，同时原配方具有更大的跨期标准差和相邻期变化。以末10期T1000早期阶段为例，原始均值−0.173615；独立校正后−0.028720，原配方−0.012856。跨期标准差则从原始0.141035变为独立0.146691、原配方0.163840；平均相邻期绝对变化为原始0.149743、独立0.161748、原配方0.225409。

这说明平均偏差校正和逐期稳定性需要各自验收。该阶段仅10个活动，lag1相关和波动统计作为描述，保留每阶段原始值及校正值供 D/H 复核。源文件为 `c1_002_scores/event_rank_phase_residuals.csv` 与 `cross_event_stability.csv`。

## 数量、跨度及剩余差异

N32full 与 N16span 使用相同首末训练期，三个终点跨度分别297、305.875、341天；活动数量由32减为16。N16recent 也是16活动，跨度分别145、153.875、175天。稀疏选样同时改变活动组成；训练前缀数量也随实际缺失变化，完整清单在 `history_groups.csv`。

各组共同训练拟合的类别编码产生56或57维输入，因此共享/独立的精确参数匹配只在同一 `(endpoint,group)` 内成立。跨历史组还包含类别支持、输入维度及组成变化。各结构在同组使用相同的输入变换、目标和缩放；独立网络只接收自己的排名训练行。

共享为无偏置d→32编码器与两个32→1头；独立为两个含偏置d→16编码器及各自16→1头。两者总参数均32d+66，实际为1858或1890。`C2_actual_parameter_equality.csv` 按每个终点/历史组/种子逐项核对实际 torch 参数数。编码器宽度、偏置位置和共享监督仍有差异，精确总参数数仅消除容量计数这一项混杂。

## 实际预算

训练均为AdamW(lr=.002, weight_decay=.05)、完整批次、无早停，活动等权且活动内排名等权。实际各组预算为：

|结构|物理拟合数|optimizer.step次数|标量参数更新次数|训练forward线性MAC|fit CPU秒|fit墙钟秒|
|---|---:|---:|---:|---:|---:|---:|
|共享60|27|1620|3,044,520|2,391,920,640|0.517498|0.557982|
|共享30|27|810|1,522,260|1,195,960,320|0.248533|0.248688|
|独立60|54|3240|3,044,520|1,175,604,480|0.563020|0.563908|
|合计|108|5670|7,611,300|4,763,485,440|1.329051|1.370578|

相同60轮组的每参数更新次数相同，共享forward-MAC约为独立的2.035倍。共享30轮的线性forward-MAC比独立60轮约多1.73%，而每参数更新次数减半。公式分别为 `epochs*n*(32*d+64)` 和 `epochs*n*(16*d+16)`：共享每例计算两个头，独立每例只计算所属排名。MAC仅计训练前向线性层，未包含反向传播、SiLU、偏置、优化器、推理和预处理。CPU/墙钟计时也仅覆盖拟合循环，读取、特征、预处理和序列化另有开销；这些秒数是本机观察值，预算解释以逐项计数为依据。

进程单线程、nice19串行执行，108次拟合等于预登记数并低于总上限120。没有追加树模型或其他候选。

## 时间隔离、验证和交付

C1 每期只接收已结束且 `end_ms < query_start_ms` 的历史，当前帧剔除actual/log_error/expert__independent。每期预测落盘后立即写入35份 issuance seal，记录预测SHA、当前开始时间、历史最大结束时间和案例集合SHA，随后才进入下一期。C2 四期查询块共用冻结终点历史；当前块结果不回灌。TRAIN 标签协调器扫描只将当次历史案例的目标值转为数值并传给拟合器；查询目标由独立评分进程在盲预测封存后打开。代码从未构造默认 TemporalDataset，也没有打开验证/测试文件。

19项fixture均已通过，RED/GREEN日志在 `logs/`。覆盖严格时间相等边界、未来答案扰动、当前目标字段拒绝、空支持回退、单线替换保留另一线、相同支持代数恒等、参数/优化预算计数、活动排名权重、训练输入隔离、逐期封存、源文件变更拒绝和无覆盖写入。仓库全套unittest由PI统一排队验收，避免与其他数值工作并行。

`build_evidence.py` 只读取本目录已经封存的分数和成本，核验所有seal后生成 `evidence_001/`。其中含完整消融、逐活动配对差、参数实际计数、计算预算及来源SHA。运行入口为：

```sh
.venv/bin/python analysis/paper_upgrade_round2/20261118/workspaces/C/c_fairness.py prepare-c1 --run <new-C1-run>
.venv/bin/python analysis/paper_upgrade_round2/20261118/workspaces/C/c_fairness.py prepare-c2 --run <new-C2-run>
# PI receipt binds experiment, absolute run path and configuration SHA.
nice -n 19 .venv/bin/python analysis/paper_upgrade_round2/20261118/workspaces/C/c_fairness.py execute-c1 --run <new-C1-run> --authorization <PI-receipt>
nice -n 19 .venv/bin/python analysis/paper_upgrade_round2/20261118/workspaces/C/c_fairness.py score-c1 --run <new-C1-run> --output <new-score-directory>
# C2 uses the corresponding execute-c2 / score-c2 actions.
```

适用范围继续保留：本轮35期及训练67期来自已有探索队列；历史测试已探索、验证反复使用，本轮没有将它们作为新独立证据；元数据缺少历史时点存档，C2未使用元数据。结果属于回溯训练期时间外推诊断，未来新增活动仍待收集。B候选及λ消融由B目录独立封存，C没有复制或重选B算法。
