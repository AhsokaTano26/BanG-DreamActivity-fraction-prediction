# 已封存模型的训练集拟合表现

使用训练 198 个活动/4377 个前缀、验证 42 个活动/414 个前缀、测试 43 个活动/412 个前缀。

主指标：event-macro MAPE，先在每个活动内平均各案例绝对百分比误差，再让活动等权。单位 %，越低越好。

训练列为验证集选定检查点在原始训练前缀上的样本内拟合误差：推理模式关闭 dropout，不做稀疏增强。没有重新训练、重新拟合预处理、重新选择模型或读取验证/测试答案；后两列取已封存评分。神经配置为三种子最终分数的算术平均，不是三次 MAPE 的平均。

| 模型 | 训练拟合 MAPE % | 验证 MAPE % | 测试 MAPE % |
|---|---:|---:|---:|
| 共享 MLP | 2.520 | 5.644 | 8.975 |
| 分排名头 MLP | 2.428 | 4.680 | 8.759 |
| 双档 GRU | 2.409 | 4.491 | 8.522 |
| 双档 TCN | 2.404 | 4.577 | 8.783 |
| 多时间尺度 TCN | 2.336 | 4.620 | 8.873 |
| 跨档 Patch Attention | 2.461 | 4.877 | 8.724 |
| 门控专家 TCN | 2.305 | 5.004 | 8.845 |
| 相对终分损失 TCN | 2.180 | 4.440 | 8.944 |
| 稀疏增强 TCN | 2.542 | 4.536 | 8.670 |
| 三个神经配置等权组合 | 2.318 | 4.374 | 8.615 |
| 上一轮组合 | 2.577 | 3.885 | 8.140 |
| 当前选定混合方案 | 2.428 | 3.802 | 8.068 |

**训练拟合误差不能解释成对新活动的预测能力。** 三个集合年代、活动构成、采样密度不同，训练截断点约为 10%–98% 的多个进度位置，验证/测试是五个固定阶段；跨列差异不能全部归因于过拟合，也不能据训练列重新挑选本轮模型。

测试活动曾在早期探索中使用，不是完全未见的盲测；元数据是当前回溯快照，缺少历史时点存档。验证集还存在多轮复用限制。

全部 41 组（含 27 个单种子）的主指标见 [train_validation_test.csv](train_validation_test.csv)，训练 MAE/RMSE/P90 与排名/时点/类型/乐队细分见 [training_metrics.json](training_metrics.json)。

独立重算训练主指标最大差异 4.4e-16；现有三个运行的模型、预处理和推理代码哈希均校验，通过两条组合推理路径核对当前方案。
