# 19档共享模型：首轮补充评测与本期回放

已完成数据库独立审计、19档补充数据冻结、三个基线训练、一次独立测试评分和19档批量回放。主库仍为135,565,312字节；本轮训练未修改数据库。

## 结论

验证集选择共享排名CatBoost。活动等权测试MAPE为 **8.41%**，43个测试活动、3,757个固定案例。加入活动乐队、角色、卡牌的这一个配方没有改善验证表现；这不说明这些因素没有影响，只说明当前编码与配方未取得增益。训练拟合误差不能当作泛化准确率。

| 方法 | 训练拟合 MAPE | 验证 MAPE | 测试 MAPE |
|---|---:|---:|---:|
| 线性外推 | 20.74% | 12.10% | 12.51% |
| 共享排名 CatBoost（验证选中） | 6.95% | 7.00% | 8.41% |
| 排名＋活动/乐队/卡牌 CatBoost | 6.30% | 7.16% | 8.61% |

这是一套补充19档基准，**不能与旧两档holdout_v1整体分数直接比较，不能声称替代原模型**。T1000尤其薄弱：验证19.29%、测试20.20%，旧两档入口仍保持原方法。T1500的训练/验证均无活动，依靠连续log(rank)共享其他档位规律，14个测试活动的MAPE18.72%，所有该档输出明确标为暂定。不根据这些测试结果继续试参选优。
