# B：数学来源及贡献边界

本说明在正式训练期数值重放之前写入，不改变冻结候选。

以历史误差确定预测组合权重是既有研究方向；Bates与Granger（1969）的原论文摘要明确以两套预测的过去误差确定组合权重。[原论文出版页](https://doi.org/10.1057/jors.1969.103) 因此本轮二次风险展开、oracle系数和一维ridge收缩均不主张为新基础理论。

Feldman、Gupta与Frigyik（2014）研究多个独立分布均值的多任务平均，给出个体样本均值的凸组合，并在两任务情形分析风险最优正则强度。[JMLR原文页](https://www.jmlr.org/beta/papers/v15/feldman14a.html) 本轮活动序列存在漂移、延迟反馈及已固定基础模型，不能直接套用其独立样本均值估计的优势结论。

本轮可检验的应用与诊断增量仅包括：活动期初统一信息集；跨排名完整面板支持守卫；仅由past-issued专家损失构造的rank×phase风险系数；小样本回退和删除活动敏感性；在同一组训练外推活动中比较固定共享、自适应共享及负迁移。结果如不支持收益，应保留否定结论。A负责完整文献矩阵及进一步关系学习文献定位。
