# 活动关系、统计影响因素与结构预测实验

本轮把“活动最终总分的规模”和“已有走势之后的剩余增长”分开分析，再据此设计预测量。固定测试集上，验证集事先选定的方案将活动等权 MAPE 从 **8.920% 降到 8.140%**，相对下降 **8.743%**。数据仍为 `holdout_v1`，43 个测试活动、412 个固定时点；没有修改划分或删除测试案例。

## 1. 训练数据揭示的关系

只用 198 个训练活动、330 条完整训练曲线和 4377 个训练前缀；重复前缀以活动聚类处理，不能当成 4377 个独立活动。

**两条排名线高度同步。** 132 个完整双档活动中，最终分数对数 Pearson 相关为 **0.9793**，活动重采样 95% 区间 [0.9710, 0.9872]；Spearman 为 0.9800。分别扣除线性年代、类型、时长、乐队的回归拟合后，残差相关仍为 **0.9734**。这支持把共同分数量级与两档的相对差拆开表示，不能据此认定两条排名线互相造成变化。排名阈值来自同一玩家总体，本来就不是独立变量。

**乐队与总热度有关，但不能简单推出它能提高过程预测。** 对最终总分的回归控制年份、活动类型、时长和排名后，乐队联合检验 q≈7.1e-10；剔除不足 5 个训练活动的乐队后仍为 q≈4.0e-8。对已知当前走势之后的相对涨幅，乐队显著性却取决于年代控制方式，见下表。不能把单一模型的不显著解释为“乐队无影响”，也不能把总分相关解释为稳定预测收益。

**数据采样方式存在明显年代差异。** 训练前缀中位观测点数约 18，验证为 263；中位采样间隔约 2.775 小时和 0.501 小时。训练中仅 33.2% 前缀有符合时效要求的另一档输入，验证为 100%。因此，旧数据上测得的跨档特征收益不能直接外推到密集采样的新活动；年代和数据密度也可能混杂。

## 2. 控制其他变量后的统计关联

响应变量为 `log(最终分数 / 当前分数) + log(活动进度)`，即平均速度外推的对数修正。解释变量包括进度样条、排名交互、类型、当前规模、时长、近期增速、档位差及变化、采样间隔和乐队。数值项标准化；缺失档位差先按训练中位数填补，再构造交互。事件等权 WLS 使用按活动聚类的 CR1 协方差，t/F 自由度为 G−1，表内做 Benjamini–Hochberg 校正。下表是联合检验 q 值，**不是影响大小排名，也不是因果结论**。

| 因素 | 线性年代控制 q | 年份固定效应 q | 解读 |
|---|---:|---:|---|
| 活动类型 | 1.81e-59 | 2.56e-66 | 关联很强，时间验证也有明确预测收益 |
| 自身近期相对增速 | 1.26e-29 | 4.05e-27 | 不同年代控制下均有显著条件关联 |
| 阶段及排名×阶段 | 3.53e-20 | 9.49e-27 | 增长不是全程匀速，两个排名的形状也不同 |
| 跨档走势及排名交互 | 5.5e-12 | 2.55e-13 | 条件关联稳健；旧稀疏数据上的增量收益有限 |
| 活动时长 | 9.93e-05 | 2.61e-06 | 对后续涨幅有关；对最终总分的独立解释依赖年代控制 |
| 乐队 | 0.25 | 0.0102 | 显著性敏感，不能断言无作用；预测增益不稳定 |
| 采样间隔 | 0.0012 | 0.553 | 与年代混杂，不能认定为独立因果作用 |
| 当前绝对分数 | 0.423 | 0.136 | 控制相对走势后未见稳健额外线性关联 |
| 年代 | 0.204 | 1.88e-09 | 线性趋势会遗漏非线性年份变化 |

最终总分的时长检验在只控制线性年代时显著（q≈0.022），改用年份固定效应后不显著（q≈0.444）；这说明部分表面相关可能来自年代构成。主要统计表、系数和敏感性结果均保存，包含没有支持原假设的结果。

## 3. 训练内部的时间验证

以最早 98 个活动训练，依次评价后续四组各 25 个活动；每组模型只拟合该组之前的活动和预处理。下表仅使用训练数据的 100 个后期活动、按活动等权。它是机制检查，不能替代官方测试。

| 训练内时间验证 | 活动 MAPE % | 相对完整特征变化（百分点） | 配对 bootstrap 95% 区间 |
|---|---:|---:|---|
| full | 5.472 | +0.000 | [0.000, 0.000] |
| invariant | 5.277 | -0.195 | [-0.442, 0.035] |
| no_band | 5.157 | -0.315 | [-0.514, -0.129] |
| no_peer | 5.453 | -0.020 | [-0.121, 0.087] |
| no_quality | 5.621 | +0.149 | [0.037, 0.265] |
| no_type | 9.610 | +4.138 | [3.138, 5.194] |

活动类型的增量预测价值最明确。采样质量特征带来较小的改善。删去乐队特征改善此处预测；跨档特征在这批以旧稀疏数据为主的回放中没有清晰增益，不能只报告正式验证集上它表现较好的那一面。`invariant` 同时去掉乐队和绝对分数，要与 `no_band` 比较才能讨论去掉绝对分数的额外变化。

## 4. 更好的预测目标：剩余增速倍率

采用：

`预测终分 = 当前分数 + 当前平均每小时增速 × 剩余小时 × 预测增速倍率`

其中平均速度为已获得分数除以已过去小时；模型学习未来平均速度与过去平均速度的比值。预测倍率使用类型、相对增速、距结束时间、档位差及其变化等信息，部分候选分别拟合 1000/2000 线。

对应训练目标为 `log[(最终分数/当前分数−1) × 进度/(1−进度)]`。它把目前的分数量级作为已知量，重点学习后续冲刺强度；剩余时间趋于零时，预测自然回到当前分数。数值实现有正值下限和 [-6,4] 的对数裁剪，对严格零后续增长是近似；本次 4377 个训练案例没有触发裁剪，反变换一致。

候选使用 39–52 个紧凑原始特征，尝试 CatBoost/LightGBM、分排名专家、绝对误差损失，以及带排名交互的样条 Ridge。所有活动在各专家损失中合计总权重相同。没有再增加神经网络层数。样条模型用于解释和候选对照，但本轮预测表现较差，完整保留在结果里。

验证选定方案为 **25% 分排名 CatBoost 剩余增速模型 + 25% 分排名 LightGBM 修正模型 + 25% 共享 CatBoost 剩余增速模型 + 25% 上一轮组合**。前三个模型由验证排名选定，组合比例也在预登记的网格中由验证集选择。

## 6. 结论与边界

本轮证据支持：活动类型、进度与相对增速是稳定的预测信息；两档共同走势有利用价值，但其可用性受采样密度影响；乐队和年代的统计关系复杂，不能只凭相关系数或一个 p 值决定是否加入模型。最有效的改进是改变目标的结构，使其直接描述剩余增速，而非仅堆叠更多标签或参数。

后续应继续检验“共同热度 + 档位差 + 末段冲刺”的结构，优先改善 1000 线及早期阶段。所有进一步参数开发仍只在训练/验证进行，固定测试用于版本比较；真正的前瞻证据需新增活动。

**这批测试活动此前已被探索使用，不是全新盲测；活动元数据是回溯快照，缺少历史时点存档。** 统计推断为探索性条件关联；band 45 训练仅 2 个活动，Festival 仅 6 个，不作可靠的单乐队因果或热度排名。线性年代与年份固定效应给出不同结论的项目均已明确披露。
