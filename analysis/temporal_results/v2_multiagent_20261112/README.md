# 多agent联合实验结论

三个agent并行探索剩余增长目标、稳健双线融合、时期分布与训练集内校准，完成18个新配方；主入口另比较7个组合与5个历史参考，共30种方案。

验证集选中三个方向最佳模型的最终分数等权均值：双线残差CatBoost变体、分排名稳健双线融合、分排名日历CatBoost。组合不是MAPE均值，未按测试成绩重选成员。

| 方法 | 训练 MAPE | 验证 MAPE | 测试 MAPE |
|---|---:|---:|---:|
| 原单线CatBoost | 2.22% | 7.35% | 9.75% |
| 上轮双线CatBoost | 2.05% | 5.50% | 9.44% |
| 稳健分排名融合 | 1.86% | 5.21% | 9.12% |
| 分排名日历模型 | 2.08% | 5.34% | 9.74% |
| 三模型组合（验证选中） | 1.89% | 4.76% | 9.12% |

主方法T1000/T2000测试MAPE为13.51%/4.72%；原单线为14.53%/4.97%，上轮双线为14.32%/4.55%。总体改善不代表每条线、每个阶段都改善。

相对上轮双线，总体降低约0.323个百分点（相对约3.4%）。43个活动的配对bootstrap描述性95%区间为[−0.650,+0.010]个百分点，仍略跨0，尚不能宣称稳定显著收益。27个活动改善，16个活动变差。区间未作多重比较校正，不用于模型选择。

阶段表现有取舍：结束前24h为7.27%（上轮7.58%），结束前1h为2.75%（上轮2.36%，原单线1.72%）。不能只汇报有利时点，也没有按测试拼接模型。

所有候选均公开，包含验证表现较差或测试退步的配方。测试最低候选没有替换验证选中的主结果。
