# 本轮实验结论：双线 CatBoost 小幅改善，TCN 未胜出

模型由验证集预先选择为双线 CatBoost。测试结果已统一封存，没有依据测试结果继续调参。

| 方法 | 训练 MAPE | 验证 MAPE | 测试 MAPE |
|---|---:|---:|---:|
| 原单线 CatBoost | 2.22% | 7.35% | 9.75% |
| 双线 CatBoost（验证选中） | 2.05% | 5.50% | 9.44% |
| 单线阶段权重对照 | 2.09% | 7.22% | 9.83% |
| 双分支 TCN 三种子均值 | 2.13% | 6.18% | 10.59% |

双线模型相对原模型的测试 event-macro MAPE 差为 **-0.31 个百分点**（负值较好）。43 个活动配对 bootstrap 的描述性95%区间为 **[-1.67, 1.18]**，包含0，不能据此断言总体改善稳定或显著。32个活动改善、11个活动变差。区间没有做多重比较校正，不用于选择模型。

双线 CatBoost 测试 T1000/T2000 为 14.32%/4.55%，原模型为14.53%/4.97%。TCN 均值的 T1000 为13.92%，但 T2000 为7.25%，合计未胜过原模型。阶段权重对照总体也未改善。

时间结果存在权衡：双线模型结束前24h为7.58%（原8.04%），结束前1h为2.36%（原1.72%）。不能只汇报有利时点，也没有使用测试结果拼接模型。

配对覆盖在训练为950/2229（42.6%），验证为1548/1548（100%），测试为1512/1514（99.9%）。这是需要关注的输入分布差异；目前不能证明它就是泛化差距的原因。缺失配对没有删案例，也没有作为零分观测输入。
