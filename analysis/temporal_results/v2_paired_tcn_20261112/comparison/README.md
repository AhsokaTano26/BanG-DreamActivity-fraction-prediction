# 同活动配对比较

独立评分脚本 score.py 只读取已封存预测与冻结标签，不参与任何训练、特征工程或模型选择。按冻结 case 的活动归属先计算活动平均APE，再对43个活动配对重采样5000次，种子42。

| 方法 | 新模型减原模型 MAPE/百分点 | 95%下界 | 95%上界 | 改善/变差活动数 |
|---|---:|---:|---:|---|
| catboost_paired | -0.3117 | -1.6683 | 1.1832 | 32/11 |
| catboost_phase | 0.0821 | -0.1787 | 0.3412 | 21/22 |
| dual_tcn_mean | 0.8351 | -0.2283 | 2.0029 | 24/19 |

负差值表示新模型误差更低。所有区间都是未作多重比较校正的描述性边际区间；本轮三种区间均包含0。不能据此断言稳定改善，也不把“不显著”解释为模型等效。

比较结果另外封存于 evaluation_manifest.json，不覆盖主评测的 evaluation_manifest.json；相同脚本重复执行只返回已校验缓存，不再次读取答案。

限制：测试活动曾被探索；元数据是回溯快照，无历史时点存档。
