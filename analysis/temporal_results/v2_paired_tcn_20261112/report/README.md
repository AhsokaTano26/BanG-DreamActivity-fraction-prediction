## 双线可用性与实验边界

| 分组 | 全部案例 | 配对可用 | 可用率 | 无同请求时点配对 | 截断后不足质量条件 |
|---|---:|---:|---:|---:|---:|
| train | 2229 | 950 | 42.6% | 1127 | 152 |
| validation | 1548 | 1548 | 100.0% | 0 | 0 |
| test | 1514 | 1512 | 99.9% | 2 | 0 |

仅配对同活动同请求时点的盲前缀，并将另一档截到当前线的实际已观测时刻。截断后为空、不足4点或过旧则保留为缺失。不同分组的配对覆盖差异会影响迁移，不能把双线模型的差异只归因于网络优劣。双线 CatBoost 与 TCN 看到相同原始特征信息；与原基线相比，新增内容包括双线特征及显式观测掩码。

阶段权重对照保持原单线特征、模型参数和案例不变，只在每个活动内部按 <25%、25%–90%、>=90% 的互斥进度阶段均分权重，再保证每活动总权重相等。它不能创造缺失的早期观测。

TCN 采用两条3层因果卷积分支、全前缀均值与末端状态汇总、表格分支及排名专用输出头。与树模型相同，目标是线性外推的 log 增长残差，按活动等权平方误差训练；本轮没有同时加入新的乐队/卡牌特征。
