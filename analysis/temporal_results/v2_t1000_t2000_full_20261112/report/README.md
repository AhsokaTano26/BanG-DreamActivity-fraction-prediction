# T1000 / T2000 完整 V2 训练与评测

验证集选择的主方法为 **新训 CatBoost：曲线**，全部测试时点的 event-macro MAPE 为 **9.75%**。

本次使用两档全部可用 V2 训练前缀重新拟合固定 CatBoost 配方。验证集只选择主方法，测试评分前已完成模型及预测封存；没有把验证/测试活动终分加入训练。

新模型的训练组数值是拟合误差，不代表泛化。旧冻结模型一栏是在已参与旧模型训练的活动上回放 V2 时点，并非旧模型原训练案例的拟合误差。旧模型使用 19 档训练，新模型使用两档及 V2 时点，因此同案例对照同时包含排名范围和训练采样变化，不能单独归因于其中一项。

固定配方：600 棵树、深度 5、学习率 0.035、L2 12、种子 42；未依据测试分数搜索参数。元数据版包含活动类型、乐队/角色与按国服发布时间过滤的卡牌特征。本轮没有新增神经网络训练。
