# V2 两档时间迁移探索

本轮只比较六个事先声明的时间迁移配方，使用冻结的
`data/temporal_holdout_v2_t1000_t2000/`，指纹为
`1f76f39af8151bba185496411bbcee064b16a4c5aca5c515c1d957a5056fe854`。
全部配方使用相同的 2229 个训练前缀、196 个可拟合活动，以及 1548 个验证
前缀、42 个验证活动。测试前缀和测试答案均未用于本探索。

`analysis/research_shift.py` 提供 `recipes()`、
`fit_recipe(config, train_arrays, train_labels)` 和
`predict_recipe(bundle, arrays)`。输入由 `prepare_paired` 产生；模型仅消费盲
前缀。新增特征来自公开的活动时间安排，包括开始/结束的星期与钟点、年内
周期、年代趋势、剩余周末时长，以及这些量与进度、排名的交互。未加载数据库、
完整验证/测试曲线、历史测试结果或卡牌元数据。

训练先在全部排名的案例上构造每活动总量相同的权重。分排名模型仅切片该
向量；按阶段平衡的候选也保持每活动总量相同，没有把近期活动额外加权。
校准候选将训练活动按真实开始时间分为前向块，每个块只用在该块开始前已
结束的训练活动拟合模型和预处理，再用这些训练组内 OOF 预测拟合排名×进度
的 MAPE 标量校准，并向全局 OOF 校准收缩。验证答案不参与任何拟合。

| 配方 | 训练拟合 event-macro MAPE % | 验证 event-macro MAPE % |
|---|---:|---:|
| 分排名日历 CatBoost | 2.0799 | **5.3441** |
| 分排名日历 CatBoost + 时序 OOF 校准 | 2.1920 | 5.4927 |
| 合并排名日历 CatBoost | 1.9512 | 6.0209 |
| 合并排名日历 CatBoost + 时序 OOF 校准 | 2.0635 | 6.3291 |
| 活动内阶段平衡的日历 CatBoost MAE | 1.4361 | 7.8103 |
| 年代外推 Ridge | 4.4139 | 10.3632 |

验证选择为 `shift_calendar_rank`。其 case-MAPE 为 5.3858%，P90 为
12.5082%；T1000 和 T2000 的活动平均 MAPE 分别为 7.2767% 与 3.4115%。
距结束 24h、6h、1h、0.25h 的活动平均 MAPE 分别为 3.2941%、2.2708%、
2.8516%、3.7203%。这只是本候选组的验证结果，不能据此声称固定测试集改进。

全部配置、源码快照、依赖版本、模型、训练权重、OOF 时序审计、逐案例训练/
验证预测和完整时点×排名结果保存于
`analysis/research_development/shift_20261112/`。使用最终的
`artifact_receipt.json` 核验文件；早先的 `development_manifest.json` 在运行
日志结束之前生成，其日志散列只对应当时状态。六个持久化模型均已重放验证
预测并核验每活动总权重；专用测试 5 项通过，全套测试 124 项通过。
Ridge 的加权标准化在近常量方差上产生过一次数值警告，预测均保持有限；
该配方未被选择。

本项目测试活动队列曾出现在早期探索中，不能称为完全未见的盲测。项目元
数据也是当前回溯快照，缺少历史时点存档。本分支不读取元数据，但这两个
限制仍适用于后续整体比较与报告。
