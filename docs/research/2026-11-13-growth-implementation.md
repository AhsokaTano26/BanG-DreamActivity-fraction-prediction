# 正增量解码器实现记录

本轮实现 `analysis/innovation_growth.py`，只接受公共适配器提供的盲前缀数组。
三种配方在性能评测前固定：`growth_direct`、`growth_progress`、
`growth_dual_clock`。没有在本模块读取数据集、SQLite、元数据文件、验证标签或
测试标签；完整训练与独立评分由公共运行器负责。

三者均使用自身排名的 `base` 特征表（含 33 点前缀）及额外的 0/1 排名索引。
没有使用另一档曲线、历史完整曲线、乐队份额或新增的上下文输入。
原始 `base` 中已有的活动类型保留在三者共同输入中。预处理仅在传入训练数组
拟合：数值中位数插补、均值与标准差缩放，缩放后固定裁剪到 [-20, 20]；
全缺失数值列以 0 填补并保留。预处理器保存各数值列在训练中是否有有限观测
的掩码；从未观测的列在预测时即使出现有限数值，也固定输出标准化后的 0，
防止启用未经训练的随机输入权重。类别词表只来自训练，未知类别编码全零。
预测不会扩展词表、更新中位数或重新拟合尺度。

编码器固定为 Linear(d, 32) → GELU → Dropout(0.1) → Linear(32, 16)
→ GELU → Dropout(0.1)。输出头分别为 1、3、5 个标量。单种子参数量为
`32d + 560 + 17q`，其中 q 为输出数；执行时强制不超过 20,000。
合成集成测试的 d=38，因此三头分别有 1,793、1,827、1,861 个参数。
实际实验的训练词表决定 d，精确参数量随模型 bundle 保存。

训练固定为 AdamW，学习率 0.001、weight decay 0.005、batch size 128、
梯度范数上限 1、80 轮；不早停，不接收验证数据。仅小型测试通过配置将轮数
改为 2。每个配方训练种子 42、123、2026，返回三个最终分数的算术平均。
逐种子预测通过 `predict_members` 提供给报告，不能单独参与选择。
每个活动在全部前缀上的总权重相同，优化加权平方 log-final 误差。
最后一个小批次也使用固定 batch size 分母，避免其样本因批次较短被额外加权。

设当前分数为 c，实际已观测进度为 p，剩余小时为 h，活动小时为 D。
代码要求两种时钟一致：`h = D * (1-p)`，避免把请求时刻与观测时刻混合。

- 直接头输出 z，`F = c + c * exp(clip(z, -20, 20))`（c>0 时），等价于
  `log(F/c) = softplus(clip(z, -20, 20))`。c=0 的合成边界以训练速率下限
  乘以 1 小时作为分数尺度；h=0 时直接返回 c。
- 进度头对三个 Bernstein 二次基函数 `(1-p)^2`、`2p(1-p)`、`p^2`
  输出 softplus 非负系数，以小时为积分单位。
- 双时间头保留相同三个进度基函数，增加两个固定末段基函数
  `max(1-h/24, 0)`、`max(1-h/6, 0)`，同样使用 softplus 系数。

两个积分头使用 `F = c + s * Σ a_k I_k`，I_k 为基函数在当前实际观测
时刻至结束的解析积分，单位为小时，s 单位为分数/小时。
s 是当前分数除以已观测小时（分母最低 1 分钟），再取不低于训练前缀速率的
活动等权第 1 百分位数，数值下限 1e-6。训练确定的速率下限随 bundle 保存。
进度系数初值为 1；双时间头的末段系数初值也为 1，因此包含明确的初始末段
额外增量。直接头初始为两倍当前分数。

`basis_integrals` 也允许积分到结束前的任意合法未来时刻；因此可检查在
固定前缀、固定系数下未来累计分数不下降。h→0 时积分增量自然归零，h=0
精确返回当前分数。三种子平均后再次保留精确结束边界及当前分数下界，
防止平均相同浮点数造成约 1e-16 的舍入偏差。这里不要求不同观测更新后
重新给出的终分预测单调。

bundle 包含完整配置、训练拟合的预处理器与速率下限、训练案例 ID、活动数、
逐种子 NumPy 参数状态、逐轮训练损失以及参数量；可直接 joblib 持久化。
模块导入不加载 PyTorch，训练和预测时才加载。PyTorch 集成测试在隔离
子进程执行，采用项目 `.venv/bin/python`，未修改已安装依赖。

验证记录：先运行新增测试，6 项均因模型模块尚未实现而失败；实现后 6 项
通过。额外的非整数当前分数结束边界测试先复现集成浮点偏差，再修正通过。
覆盖解析积分的手算小时值、非负未来增量、活动总权重、全缺失列与未知类别、
预测不修改预处理、三种子最终分数平均、精确零时长、重复拟合确定性及保存
重载一致性。正式性能运行前的同行复核另补训练全缺失列在预测期出现有限值
的边界测试：先复现非零激活，再保存训练观测掩码并固定零回退，序列化重载
也保留该行为；最终 7 项测试通过。独立命令为
`.venv/bin/python -m unittest tests.test_innovation_growth -v`。
完整仓库测试、正式训练和数据完整性验证由主运行器任务统一执行。

本轮仅有终分监督，没有额外区间增量目标。不同基函数系数组合可能给出相同
终端积分，幅度分解不可识别，不能解释成真实玩家行为或冲刺机制。
这只是固定小编码器下的解码结构消融，不是完整时间动力学识别。
测试队列曾出现在早期探索实验中，不能称为完全未见的盲测；元数据为当前
回溯快照，缺少历史时点存档。不得依据 V1/V2 不同时间网格的汇总差异
宣称模型改进。
