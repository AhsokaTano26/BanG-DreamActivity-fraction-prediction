# 固定历史检索模型实现记录

实现文件为 `analysis/innovation_retrieval.py`，测试为 `tests/test_innovation_retrieval.py`。
本记录仅说明实现与合成测试，没有读取冻结验证／测试答案，也没有给出模型精度结论。
正式训练、全库测试和独立评分由统一 runner 完成。

## 固定候选与边界

- `retrieval_control`：现有自身前缀特征，CatBoost 学习相对于线性外推的对数终分残差。
- `retrieval_features`：在相同输入和目标上加入检索先验、增长倍数分布、距离、覆盖与滞后特征。
- `retrieval_residual`：使用相同扩展特征，学习相对于检索先验的对数终分残差。

三者固定为 600 棵树、深度 5、学习率 0.035、L2 12、种子 42、2 个线程；
只有 `iterations` 支持合成测试的较小值。每活动总训练权重相同。插补与类别编码只在
传入训练行拟合；未见类别忽略编码，全缺失数值列保留并填 0，预测不改变训练 schema。
最终解码约束对数增长在 `[0, 4]`，所以终分不低于当前分数。训练先验仍使用真实线性
外推，尤其早期进度小于 `exp(-4)` 时不能提前截断先验、改变残差目标。

历史库完全由 runner 提供；模块没有数据文件或数据库读取入口。拟合时复制历史数组，
保存每条曲线的活动、排名、类型、时间、观测数、终分和 SHA-256；模型重载后仍使用
该副本，忽略预测参数中的新历史。runner 因此可以固定官方训练库或每个时间折的训练库，
包括属于训练组但没有该网格训练前缀的活动。模块不会通过案例列表另删这些合法历史。

检索仅接纳相同排名、不同活动、`history.end < query.start` 的曲线。按查询实际进度截断
历史前缀，要求至少 4 点、末次观测滞后不超过 60 分钟、至少 2 个共同形状锚点。
形状锚点为当前可见时长的 25%、50%、75%、90%，只在各自已观察前缀内部插值。
距离固定为形状平均绝对差加 `0.15 * abs(log(当前规模比))` 加 `0.2 * 类型不同`；
按距离、活动 ID 排序取 5 个历史活动。每活动排名最多一条历史，重复则报错。
增长倍数的中位数构成先验，分位数、IQR、标准差、距离、候选数量、历史年龄与观测
滞后同时供模型判断历史可信度。少于 5 个合格邻居时不启用检索先验：保留案例，
回退线性外推，记录候选数、零选中数与 fallback 标志。查询意外附带的未来后缀会截掉。

## 验证记录

命令：`.venv/bin/python -m unittest discover -s tests -p test_innovation_retrieval.py -v`。
结果：13 项测试全部通过。初始缺模块时测试先失败；早期线性先验与固定配方声明
一致性的补充回归也分别观察到失败后修正通过。

覆盖同活动、未结束与恰好在查询开始时结束的历史、错误排名污染；固定 5 邻居；
稀疏与空历史；缺少共同形状；60 分钟滞后边界；查询未来后缀；重复历史拒绝；
事件等权；三配方未知类别与全缺失列；输出顺序；传入历史变化与原数组修改不影响
已拟合模型；joblib 保存重载一致；负增长约束；固定配置不得宣称未实现参数。

全库 `.venv/bin/python -m unittest discover -s tests -v` 由主代理统一运行，
此记录不把局部测试称为全库通过。没有改动旧模型、旧评分器、冻结数据或已封存结果，
没有提交 git commit。

共同限制仍然保留：测试队列曾参与早期探索，不能称为完全未见的盲测；元数据是回溯
快照，没有历史时点存档。V1 与 V2 不同时间网格的汇总差异不能被解释为模型改进。
