# 两档活动终分预测的结构研究建议

建议优先验证小型正增量动力学模型，再验证共同热度与排名间距模型；自监督表示加残差适配应作为独立研究方向。活动类型和乐队的层级收缩可以作为前三者共享的条件化模块。下述方案是针对冻结数据条件的研究假设，借鉴既有文献并重新组合，不构成原创性或效果声明。

## 数据条件与现有方法边界

遵循 `AGENTS.md` 的 V2 两档冻结子集 `data/temporal_holdout_v2_t1000_t2000/`，指纹为 `1f76f39af8151bba185496411bbcee064b16a4c5aca5c515c1d957a5056fe854`。正式监督训练仍为 2229 个前缀、196 个有效活动，验证为 1548 个前缀、42 个活动；不能把前缀数量当成独立样本量。训练双线配对覆盖约 42.6%，验证为 100%，因此配对可用性本身存在分布差异。

现有 `temporal_paired_features.py` 已包含自身和另一档归一化 33 点序列、可用标记、分数比、差距、短窗速率比、比值变化、对方数据滞后；`temporal_paired_network.py` 使用两条 TCN 编码器、表格分支和两个排名输出头。`research_remaining.py` 已比较剩余速率目标、final/current 目标和分排名拟合；`research_fusion.py` 已使用单线/双线分支、屏蔽副本、固定与进度门控、滞后衰减；`research_shift.py` 已包含日历、年代、阶段平衡和训练组内前向 OOF 校准。这些因素可以作为控制组，不能改名后作为新结构。

所有新增特征只来自当前合法盲前缀、已知活动时间安排及获准的元数据。另一排名必须遵守既有同活动、同请求时刻、同 split 配对，并截断至当前案例实际已观测时刻；不从未来请求案例补齐。插补、尺度、词表和正则化配置的拟合仅使用训练组。训练完整曲线的使用必须经过冻结数据读取器校验，只能来自相应 `train_curves` 文件。

## 一 正增量与末段冲刺的双时间轴模型

设活动开始、结束分别为 S、T，当前实际已观测时刻为 t，当前分数为 c，时长 D=T−S。同时保留进度 p(u)=(u−S)/D 和剩余小时 h(u)=T−u。积分起点是 t，不能用请求时刻代替实际观测时刻，否则会漏算观测滞后期间的增量。

一个宽度 16 或 24 的时间感知编码器从合法前缀输出少量系数，解码器使用非负速率基函数：

```text
v̂r(u | prefix) = sr · [Σk softplus(ak) Bk(p(u))
                         + Σj softplus(bj) Ej(h(u))]
F̂r = c + ∫[t,T] v̂r(u | prefix) du
```

`sr` 是只依赖当前前缀的分数/小时尺度；例如当前平均速率并使用训练组确定的数值下限。`Bk` 是少量平滑、非负的进度基函数，表达全程形状；`Ej` 是预先固定、仅在末段有支撑的非负小时基函数，例如最后 24h 和 6h。首轮使用固定基函数和可解析积分，只学习幅度，避免一开始同时学习冲刺开始时间、宽度和高度。

这样从任一前缀生成的未来分数轨迹不下降，预测终分不少于当前分数，剩余时间趋近零时剩余增量自然消失。它不保证不同观测时刻重新生成的终分预测单调；后者也不是必要的物理约束。两个时间轴解决的问题不同：同一活动进度与同一“离结束还有 6 小时”并不等价。

与已做的 remaining-rate 目标相比，这里的新部分是**非负未来轨迹解码、进度形状与绝对末段时间的分解，以及训练曲线中的多个区间增量监督**，而非再次更换一个终分标量目标。仅用终分监督时，不同基函数组合可能给出相同积分，不能把分解幅度解释为真实玩家行为。可从训练完整曲线构造辅助区间增量损失，但必须另列训练来源，保留全部正式前缀，按活动归一化辅助损失。

应验证：同编码器下直接终分头对比积分头；仅进度基函数对比进度加剩余小时基函数；仅终分损失对比加入训练区间增量损失；固定 33 点表示对比保留原始时间间隔的表示。不要一次同时更换编码器、输入和损失。重点观察不同活动时长、最后 24h/6h、观测滞后分层以及原有共同面板。

主要风险是末段训练活动不足、平滑基函数掩盖突发冲刺、基础项与冲刺项不可辨识，以及早期前缀无法确定未来冲刺幅度。后两项应通过强正则和低维系数处理，不应靠加宽网络解决。排名线是聚合阈值，不能从这些数据识别玩家人数或个体决策；冲刺分解只能称为行为形状假设，不建议把分数上升直接解释成 Hawkes 自激事件。

依据是 N-BEATS 对基函数预测与结构化解码的思路；这里的正增量和末段小时基函数是任务特定假设，论文并未验证这些选择。[N-BEATS 原论文](https://arxiv.org/abs/1905.10437)

## 二 共同热度与有序排名间距的联合模型

两条曲线可以由一个低维共同状态表达活动热度，再用排名特定状态表达竞争强度与间距。编码器保留每档的实际时间、滞后和缺失掩码；共享状态只聚合可用档位，缺档时由自身前缀及训练先验得到共享状态。缺档不能编码成真实零分曲线；有序解码可把未知档位的分数下界设为 0，但必须以掩码明确这是下界而非观测值。

对于同一个合法信息集，记已知分数下界为 c1、c2，分别对应 T1000、T2000。一个简单的可行解码为：

```text
q2 = 非负剩余增量头(shared_state, rank2000_state)
qg = 非负超出下界的间距头(shared_state, gap_state)
F̂2000 = c2 + q2
F̂1000 = max(c1, F̂2000) + qg
```

`q2` 和 `qg` 可以使用第一种结构的积分输出，或乘以对应合法观测时刻的剩余时长。这个参数化覆盖所有满足终分不低于当前下界、且 T1000 终分不低于 T2000 的可行终分对，不要求两档未来增量大小有序，也不要求当前分数差继续扩大。例如当前 `(100,60)`、最终 `(110,100)` 合法，未来增量为 `(10,40)`；不应约束 `Δ1000≥Δ2000`、增量比值大于 1 或间距随时间递增。

最需要注意的是信息集。既有两个案例可能有不同的实际观测时刻 t1、t2。每个案例用自己的合法信息集生成内部有序向量是合法的，但分别取两个案例各自的主排名输出后，不能再声称它们必然有序。若要输出一对严格一致的联合预测，需先把两档都截断到 `tc=min(t1,t2)`，用共同信息集联合预测；这会牺牲较新一档的信息。该实验必须增加同样截断到 tc 的独立双头控制组，才能把结构收益与信息新鲜度损失区分开。不能把各自最新的两条预测事后联合排序，因为这可能让较旧案例间接使用对方较晚的信息。

应验证：独立编码器/独立头对比共享低维因子；同共享因子下无序双头对比有序解码；有序解码对比仅推断投影；真实配对对比同案例屏蔽另一档。每个结构对照使用完全相同的合法输入，配对缺失案例全部保留。共享因子维度先限制为 2–4，不能把只有两档的任务直接扩成复杂图网络。

主要风险是共同热度假设过强、两档冲刺机制不同、较差的一档通过有序层拖动另一档，以及训练配对覆盖不足导致共享分支在验证中失配。先报告无约束模型有多少同信息集预测真正违反排名顺序；若违反极少，硬顺序约束的直接收益可能很小，共享状态是否有用才是主要问题。

Deep Factors 提供共享全局因素与局部因素分解的借鉴，但论文面向大量序列；本项目只有两个排名、有效活动较少，因此这里只采用小型因子和局部残差思想，不宣称其原论文结果可以迁移。[Deep Factors 原论文](https://arxiv.org/abs/1905.12417)

## 三 训练曲线自监督表示与少样本残差适配

目的不是增加网络容量，而是让少量活动中的大量已观测区间先教会编码器识别节奏、变速、缺测和滞后，再用小型头学习终分修正。本方案首轮选择冻结训练曲线中的两档、已有正式训练前缀的 196 个活动，使监督训练与预训练的活动支持集一致；这不是 AGENTS 对辅助学习范围的普遍禁止。若把活动 57、68 在 `train_curves` 中的训练历史作为额外自监督数据，应显式记录辅助信息预算、活动权重及有无这部分历史的对照，不移动活动分组。同样，从父 19 档队列引入额外训练历史时也应另列信息预算与对照，不能直接归因于网络结构改善。

首轮可以只预声明两类任务：在同一截断时刻下随机稀疏采样的两种前缀视图做表示一致性；用历史截断前缀预测随后某一训练区间的分数增量。后者的未来片段只作训练目标，不进入输入。任何归一化均使用该视图已知的当前分数或训练组尺度，不能除以整场最终分数。不要对时间做任意扭曲，因为最后 6h 的物理含义不能由增强破坏；也不要把明显不同阶段的前缀强制学成相同表示。

令冻结的训练组基线终分为 F0≥c，编码器表示为 z，低维残差头为 δ(z,p,h,rank)，一种输出为：

```text
F̂ = c + (F0 − c) · exp(δ)
```

当 δ=0 时恢复基线；δ 可以降低或提高剩余增量，预测仍不低于当前分数。若基线在尚未结束时恰好预测 F0=c，这个乘法头无法恢复正增量，需预先约定训练尺度下的极小剩余增量下限，且下限必须随剩余时长归零；这属于明确的数值设计，不应事后根据验证表现调整。

残差训练目标应基于按活动、按真实时间前向得到的训练组 OOF 基线预测，不能用高度拟合的训练内基线残差。每个 OOF 基线只能拟合该块开始前已结束的训练活动及其预处理；最终基线再在全部正式训练活动上拟合，不加入验证活动。若对 OOF 本身报告前瞻性能，预训练器与残差头也必须置于相应外层时间折内重拟合；仅用全训练组预训练表示生成 OOF 残差训练特征，不能把该 OOF 分数另称严格前瞻验证。

不规则时间输入使用 `(分数或区间增量, Δt, 进度, 剩余小时, 各档掩码, 距该档上次观测的时间)`。长缺口中的平均速度不等于瞬时速度，应保留区间长度和覆盖标记。先采用小型时间感知 GRU 或带时间通道的编码器；Neural CDE 是处理不规则、部分观测多变量序列的一个可选编码器对照，不宜在首轮同时引入求解器、复杂预训练和更大的网络。[Neural CDE 原论文](https://arxiv.org/abs/2005.08926)

应验证：完全相同架构随机初始化对比自监督初始化；冻结编码器加线性/低秩头对比全量微调；自监督表示对比手工特征驱动的同容量残差头；原始不规则时间对比相同掩码的固定网格；仅训练曲线稀疏增强对比无增强。正式监督案例仍为 2229 个，辅助视图另计；各活动的辅助任务总权重相同，不能让快照更密的活动占据更多训练权重。

主要风险是模型记住活动身份或采样频率、对比学习制造相似活动的假负例、归一化丢掉绝对热度、插值让模型误认密集观测、以及 OOF 基线与全训练基线的残差分布不同。小型冻结编码器、较弱增强、独立保留绝对分数特征和强收缩残差头比端到端大网络更符合当前样本量。

TS2Vec 的层级对比表示可作为多尺度前缀视图学习的参考；其论文不等于已经证明本项目的稀疏配对、单调累计分数或冻结测试协议下有效。[TS2Vec 原论文](https://arxiv.org/abs/2106.10466)

## 四 稀疏活动条件的层级收缩

训练元数据诊断显示 7 种活动类型，类型与乐队的 49 个组合中有 41 个不超过 5 个活动，并存在较多 mixed 条目；因此直接学习每个组合的大 embedding 或独立输出头容易记忆活动。该统计针对训练元数据队列，真正拟合时仍以 196 个有效活动重新计算每个层级的支持数，不能使用每组的前缀数量替代活动数。

可将第一种结构的基函数系数或第三种结构的残差头条件写成：

```text
ηe,r = μr + αtype(e),r + βband(e),r
       + utype(e)ᵀ vband(e) + f(prefixe,r)
```

类型、乐队主效应采用零均值收缩，交互项限制为秩 1–2，并使用比主效应更强的正则。少见乐队回退到类型与全局主效应，未知类别回退到零偏移；不为极少样本组单独拟合网络。若 mixed 具有合法且稳定的成员构成字段，可使用多热成员的加权主效应；如果只有 mixed 标签，就保留该标签和缺失状态，不能推测成员。

应验证：相同前缀编码器的无元数据、简单 one-hot、仅收缩主效应、再加低秩交互四种对照。重点看验证中训练支持数较低/未见组合，不能只看总体平均。正则强度只在预声明的小候选集中由验证选择；历史最终热度仍需遵守本活动及尚未结束活动排除规则，卡牌仍按国服发布时间过滤。

这个模块的变化在于对数据稀疏性的显式建模和跨组共享；把已有 one-hot 输入换成普通 embedding 本身不构成充分的新方法。主要风险是乐队效应与年代、活动类型高度混杂，收缩只能减少方差，不能把回溯关联解释为因果热度。

## 最小实验顺序与共同验收

首轮优先固定输入信息和小型编码器，仅比较直接输出、正增量积分、双时间轴积分三个解码器；同时保持原树模型作为参考。第二轮在完全相同信息集上验证共享因子及有序解码。自监督与层级收缩分别做独立消融，避免四项改动一起出现后无法归因。

每轮在读取新的验证表现前冻结候选与消融，不依据测试结果扩展网格。神经网络固定种子 42、123、2026，逐种子报告并以三个最终分数的算术均值作为集成，不能选择最好种子。训练每个活动总权重相同；辅助任务、配对复制和联合输出都不能改变活动总权重。验证仅选择候选和轮数，不拟合预处理、校准器或热度历史。

所有方法覆盖相同正式案例；按 event-macro MAPE 选择，同时报告 case-MAPE、MAE、RMSE、P90、时间点×排名×活动数、缺失和滞后分层及冻结共同面板。测试盲预测在新目录封存，之后只由独立评分器评分一次。数据、代码、依赖、预处理、辅助视图清单、模型和预测均需指纹，不覆盖任何现有运行。

测试活动队列曾出现在早期探索中，不能称为完全未见的盲测；元数据为当前回溯快照，缺少历史时点存档。这两项限制继续适用于全部候选。
