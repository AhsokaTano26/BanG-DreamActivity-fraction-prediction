# 基于固定数据集的新方法研究

本轮目标是提出可证伪、适合当前数据量的新模型设计，并用训练组内诊断判断研究优先级。下述结构尚未完成正式训练；已有的小实验另列，不能把它们当成 V1/V2 测试改进。这里的“创新”指本项目尚未验证的结构组合，不主张文献首创。

## 当前证据与研究边界

- 保留 V1：`d0ccf9f70aee19ad1b2152925e7afe8692d67f4a6e539d558f87e2cd33329bbb`。
- 本轮训练诊断使用 V2 两档：`1f76f39af8151bba185496411bbcee064b16a4c5aca5c515c1d957a5056fe854`。
- 训练组有 198 个活动、330 条合格完整历史曲线；冻结时间网格实际产生 196 个活动的 2229 个前缀。活动 57、68 继续保留原分组。
- “类型 × 乐队”有 49 个已出现的组合，其中 41 个只有不超过 5 个活动。混合乐队活动有 74 个。不能把稀疏组合直接拆成大量独立模型。
- 既有双线特征的训练配对覆盖是 950/2229（42.62%），按每活动等权则为 24.10%；验证是 1548/1548。训练缺失的 1279 个案例中，对档完整曲线缺失 344 个、有对档曲线但该时点前缀不合格 783 个、截断到自身已观测时刻后无效 152 个。这表明模型需要处理观测条件变化；单靠给网络增加参数不一定解决问题。
- 上轮已经研究过：剩余增长目标变换、分排名树模型、固定进度门控、缺失排名增强、日历特征、训练组时序 OOF 校准。以下方向需要与这些已有方案明确区分。

元数据计数可复现脚本及输出：`analysis/innovation_research/20261113/context_profile.py`、`context/profile.json`。计数依据训练历史活动，每活动一次，不把快照当独立活动；类别关联不是因果效应。

训练曲线关系诊断见 `analysis/innovation_research/20261113/relations/v2/README.md`。在有可靠边界观测的训练子集中，最后 6h 增长占终分的中位数为 T1000 15.40%（43 活动）和 T2000 13.95%（24 活动）；这是稀疏覆盖下的描述性结果，不代表全体活动。50%/90%/剩余6h 的同步跨档面板仅有 12/16/18 活动，且偏向近期年份，不能仅凭较高相关系数认定联合模型一定有效。训练曲线采样还存在明显年代差异：2024 年每曲线观测数中位数为 330、采样间隔中位数约 30min；2019–2023 年各年的对应中位数约 28–35 次和 123–218min。模型必须区分实际增长模式与观测密度变化。

## 1. 共同热度与排名间距联合建模

**假设**：两条排名线反映同一活动的共同热度，但 T1000 与 T2000 的差距还包含竞争强度信息；直接分别预测两个终分，会浪费共享信息。

编码器由小型时间网络或树模型构成，分别表示共同状态和排名差异；同时监督两个终分及其对数比值。除已知排名外，不把活动 ID 当可记忆的输入。加入分类型/乐队的低维条件，但使用收缩防止稀疏类别过拟合。

在同一信息时刻 t，令 H 为剩余时长，可以使用两个有约束的输出：

```
F2000 = S2000(t) + H * softplus(a)
F1000 = max(S1000(t), F2000) + H * softplus(b)
```

这样保证终分不低于当前分数、T1000 终分不低于 T2000。**不要求 T1000 的未来增量一定大于 T2000 的未来增量**。

必须处理的边界：两档观测常常不同步。联合约束只对同一信息集下的两个输出成立；不能把较新排名观测塞给较旧案例。共同 as-of=min(两档观测时刻) 的联合版本需要与同样截断输入的基线比较，并单独报告损失的新鲜度。缺失另一档时保留案例，回退单线分支；不能只评分完整配对。

消融：相同输入/参数规模下比较独立头、共享编码器、共享+间距监督、再加顺序约束。若只在强制排序后改善而间距监督无益，就不声称发现了共同动力学。

可参考 [Deep Factors for Forecasting](https://proceedings.mlr.press/v97/wang19k.html) 的全局与局部成分思想。上述排名输出结构是针对本项目的设计提议，论文未证明其在活动排名线上有效。

## 2. 常态增长与冲刺增长的双时间轴模型

**假设**：相同 90% 进度对不同长度活动意味着不同剩余小时，冲刺可能主要依赖剩余小时，常态增长则依赖活动进度、昼夜和周末。

一次预测的未来增量由少量非负基函数组成：

```
future_rate(u) = base_component(progress(u), local_hour(u))
               + rush_component(hours_to_end(u), observed_recent_acceleration)
final = current + integral(future_rate(u), u=t..end)
```

系数由小型网络根据当前可见前缀、活动类型和乐队条件估计。可增加隐藏状态表示冲刺是否开始，并随当前活动新观测更新状态；这不是用验证/测试终分重训。

与上一轮剩余 rate 目标不同，此方法学习未来增长的时间结构，可在训练历史中增加 1h/3h/6h 增量监督；所有窗口和辅助损失仍按活动归一化。未来监督来自训练曲线，不得用于当前输入或验证/测试预训练。稀疏区间不伪造精确增量标签。

一次预测的累计轨迹可以要求非下降；**不要求不同时点给出的终分估计单调上升**。新观测可能合理地降低终分预期。

消融：仅常态、仅冲刺、两者相加；仅进度、仅剩余小时、双时间轴；直接终分监督与多时距辅助监督。先用少量可解释基函数，再增加状态空间模型复杂度。

可参考 [Deep State Space Models for Time Series Forecasting](https://papers.nips.cc/paper/2018/hash/5cf68969fb67aa6082363a6d4e6468e2-Abstract.html)。聚合排名分数不足以识别玩家人数或个体策略，不能把隐藏状态解释成已识别的玩家行为因果机制。

## 3. 检索相似历史，学习何时相信历史

**假设**：对当前前缀相似的历史活动，其后续增长可能比全局平均更有参考价值。检索信息也可能与现有树模型互补。

每次只检索当前活动开始前已结束的训练历史；以相同排名、前缀形状、当前规模、类型及剩余时长确定邻居。每历史活动最多贡献一个匹配项。使用历史曲线的未来段是允许的，因为那是已经结束的训练活动；当前查询的未来段不可见。

优先把邻居的增长倍数中位数、离散程度、距离和有效样本数作为残差模型输入，或作为可收缩先验。邻居彼此分歧大、距离远、有效数量少时，模型应降低检索影响。这个权重需要训练组时序 OOF 学习，不能用验证/测试答案拟合。

两种时钟需分开检验：按相同活动进度检索、按相同剩余小时检索。近结束阶段，历史观测滞后会直接污染增长倍数，需要显式携带滞后而非假设严格对齐。

本轮小实验仅检查固定的简单检索能否胜过线性外推；结果见独立训练组实验目录，不等价于已胜过现有 CatBoost。

本轮已经完成的训练内部小实验：按真实开始时间将前 99 场作为历史起点，后 99 场分成三个连续展示块。每个查询仅检索其开始前已结束的训练活动，历史可随训练组时间推进扩充，保留后 99 场全部 1189 个冻结案例。三个检索配方在评分前固定，未循环调参。

| 方法 | 训练内部前推 event-macro MAPE | RMSE |
|---|---:|---:|
| 线性外推 | 10.599% | 1,566,417 |
| 曲线形状，5 邻居 | 7.166% | 1,480,178 |
| 形状＋规模＋类型，5 邻居 | 5.739% | 1,648,974 |
| 形状＋规模＋类型，10 邻居 | 6.775% | 1,654,085 |

5 邻居复合距离方案三个连续块的 MAPE 为 5.284%/5.143%/6.791%，线性为 12.647%/8.058%/11.092%，80/99 活动更好；但 RMSE 更差。它没有与同条件重训的 CatBoost 比较，且使用的是训练内部滚动历史，**不得与既有固定 V1/V2 测试分数直接比较**。因此把它作为后续残差输入的候选，不宣布替换现有模型。完整四方案、阶段、排名、覆盖、逐案例预测和独立审计在 `analysis/innovation_research/20261113/retrieval/`。

参考 [Retrieval Augmented Time Series Forecasting](https://arxiv.org/abs/2505.04163)。该论文提供检索历史模式与后续值的思路，不构成本项目性能证据。

## 4. 类型、乐队、角色的分层收缩与低秩交互

**假设**：活动类型和乐队会改变增长形状及冲刺程度，而不仅仅改变终分高低。稀疏交叉组合应向总体规律收缩。

将条件效应拆成全局项、类型项、乐队成员比例项，以及低秩的“类型 × 乐队 × 进度”交互。混合活动用成员/乐队集合表示；小样本角色共享乐队层信息，未见类别回退总体。把这些条件用于调整增长基函数或小网络的少量系数，不为每个组合训练完整独立网络。

消融必须比较：原有静态上下文、仅加性分层项、低秩时间交互。控制日历年代与当前分数后再检查条件效应，并在时间靠后的训练折验证；原始类型均值或 SHAP 值不能证明因果影响。

类别词表、标准化、收缩强度都在每个训练折内拟合。卡牌仍按国服发布时间过滤。当前回溯元数据的限制保留。

## 5. 对缺失和不规则观测敏感的小型序列模型

**假设**：33 点插值可能模糊“真正平稳”和“很久没更新”的差别，网络需要同时看到分数增量、真实时间间隔与缺失掩码。

先比较带时间间隔的 GRU-D 与已有 TCN；若不规则采样确实成为误差来源，再比较 Neural CDE。训练中对可见前缀做固定的降采样和连续缺失模拟，同活动的所有增强副本总权重保持不变。增强不能生成原来不存在的未来观测。

先只用两档训练曲线进行遮蔽重建/短期增量自监督，再学习终分残差。每个内部验证折的预训练也只能用该折训练活动；不能先在所有训练活动完整曲线上预训练，再声称较后活动是 OOF。

参考 [GRU-D](https://www.nature.com/articles/s41598-018-24271-9)、[Neural CDE](https://papers.nips.cc/paper/2020/hash/4a5876b450b45371f6cfe5047ac8cd45-Abstract.html) 与 [TS2Vec](https://arxiv.org/abs/2106.10466)。这些论文分别提供缺失建模、连续时间编码和自监督表示的基础；适配后仍需在本数据集验证。切窗和增强不会增加独立活动数量。

## 6. 扩展研究：19 档排名形成连续有序曲面

在 log(rank) 轴上，用共享热度、局部斜率与曲率表示排名分数分布，采用有序样条或正间距解码。T500/T1500/T3000 等邻近线可能提供竞争密度信号，而不是为每档孤立拟合一套网络。

这是**增加输入信息**的单独实验轨道，不能与两档输入的分数差直接归因于网络。额外曲线只来自冻结训练活动；推理时仅使用父 V2 中相同案例时刻且不晚于自身实际观测时刻的盲前缀。必须保留两档相同输入对照，以及同样使用额外排名的简单树模型对照。

不优先训练大 Transformer 或生成大量虚构活动：当前限制是独立活动少、年代与观测覆盖变化，复杂结构需要以明确消融证明收益。

## 正式实验顺序与判断标准

1. 固定内部时序折、候选清单与搜索预算；按活动分组，较后活动仅由较早已结束训练活动拟合模型。预处理、自监督、检索库、路由和校准全部服从折内边界。
2. 第一批优先：分层条件模型、双时间轴增长模型、检索残差。第二批：共同热度/有序间距、缺失感知序列预训练。19 档扩展独立标记。
3. 训练组内部看每折活动等权 MAPE、T1000/T2000、早中晚阶段、末 6h/1h、缺失与完整配对分组，报告所有固定候选。内部滚动检索 pilot 与固定折拟合结果不可混作相同协议。
4. 验证集选择并封存最终配方，之后才做测试盲推理和独立评分；测试不能继续筛选。神经网络使用 42、123、2026 三种子，按最终分数均值集成。
5. V1 仍是主标准；V2 沿用相同活动归属与全部冻结时间案例。不能跨时间网格比较汇总数后声称改进；每个新模型要保留同案例基线。
6. 独立样本按活动计，活动配对 bootstrap 使用冻结 case 归属。精度收益、末段表现、尾部误差与不确定性一起报告，不承诺某个复杂模型一定获胜。

**共同限制**：测试队列曾参与早期探索，不能称完全未见盲测；元数据缺少历史时点存档。训练相关性与本轮内部实验只用于提出下一轮假设，不能替代冻结验证/测试结果。
