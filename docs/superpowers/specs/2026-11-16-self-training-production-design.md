# Self-training local forecasting product

User clarifies the final deliverable: a trained model that continuously predicts and automatically learns new data. Implement a usable local production product, not another architecture experiment. Explicit previous dense-date and leak boundaries remain authoritative. Rank scope is configurable; initial default19 ranks pending optional user preference. T1000/T2000 use the validated400-tree Context recipe plus original shrinkingEWMA; other ranks use the existing600-tree shared rank recipe. No unsupported accuracy claim for new production fits.

Architecture: a dedicated runtime SQLite store bootstraps dense local histories read-only from data/db.sqlite3, then incrementally synchronizes public Bestdori metadata/current/pending-recent curves. Code lives in production/. All runtime data, immutable trained versions, forecasts and logs live under runtime/live/. Frozen benchmark files and previous artifacts remain unchanged. No other messages are sent externally.

Clock: production training only actualCNstart>=1706504400000 and end strictly before current event start (or now when idle). A curve must have>=5 ordered finite nonnegative points, positive final, and last point within end-60sec/end+300sec; for inference only points<=requestednow. Per-activity training weights and frozen temporal origin sampling are used. Production-only supervised preparation skips origins before the first observation and prefixes whose current score exceeds the verified final (e.g. ranking removals/corrections); raw history/final remain untouched, omitted prefixes are audited by event/rank, weights are recomputed over supported prefixes. This does not change any frozen benchmark case. Never use ongoing-event final labels or pseudolabels for fitting. Keep one model/calibration snapshot per active event; after event completion refresh next model from newly eligible histories.

Model pack: trained two-rank Context bundle +19-rank shared bundle + metadata + dataset/config/code/dependency fingerprints + curve support + smoke replay verification. Immutable versions and atomic active pointer; technical failure retains last valid model. Same history/config digest reuses model rather than retraining each poll. Keep prior versions and provide rollback command. Promotion checks technical/causal validity, not a claim of future accuracy. Coverage/missing ranks surfaced in forecasts; no fabricated values.

Feedback: store unique issued forecasts by(event,rank,observed_at), including uncorrected base, corrected forecast, phase, model_id, as_of. Only verified completed outcomes update calibration. Aggregate each event/rank/phase once, then rebuild EWMA in completion chronology; alpha.3, n/(n+10),clip±.3. For known retrospective V3 bootstrap optionally use verified sealed rolling_context forecasts with matching closed local outcomes and clearly mark origin. Do not fit a correction to train resubstitution errors. Future live feedback uses actual issued forecasts; idempotent processing handles restarts/late ranks.

Operation: cycle=lock→sync→completed feedback→ensure trained pack→predict active event(s)→save latest.json/CSV+immutable forecast history/status. Configurable15minute schedule; retry next cycle with recorded error. A new ended-event dataset or corrected eligible history triggers a new model, while active-event pins preserve its model/calibration snapshot. Expose CLI bootstrap/cycle/status/run/rollback/install/uninstall. OnmacOS create a user launchd agent at a documented label/path, RunAtLoad+StartInterval900; actual install/start is within user's request for automatic operation. It runs while logged in and awake; report this operating constraint. No webserver/public publishing required.

Tests: network mock fixtures, actual-start cutoff vsIDs, unfinished/self/future exclusion, missing final retry, identical-data no-retrain, immutable registry corruption/rollback, forecast idempotency, equal-event weights, checkpoint replay, end→feedback→new-version lifecycle, lock/restart/fetch/model failure recovery. Full repo unittest. Run real initial sync/train/cycle and inspect produced trained artifacts and latestforecast/status before claiming delivery. Preserve current repo changes; no commit/push.

Resilience rulings: an unusable active pin may be replaced only by a verified causal pack, with its original pin archived and reason logged. Current pointer corruption falls back to immutable versions. Issued observation corrections create immutable revision transitions; calibration uses only the latest issued revision per observed timestamp, not multiple weights. Manual rollback pauses automatic model updates until resume-auto; this status is visible. Event catalogs refresh each cycle, reference dictionaries daily; malformed/empty catalogs retain last-good metadata.
