# 三列布局与切换过渡

桌面宽屏（>=1200px）采用三列：左侧活动信息和摘要保持原布局，中间为预测记录和图表，右侧为全部排名。右侧使用三列表格，观测时间及状态置于分数下方，完整保留原信息；列表可独立滚动，点击整行或键盘激活排名按钮均可切换。

活动或排名切换后，中间内容就绪时以约220毫秒淡入和轻微位移过渡。左侧位置保持稳定，自动刷新不触发过渡。快速连续选择以最后一次为准；系统减少动态效果设置生效。已有的首次曲线播放与悬停读数保留。

1000至1199px使用左摘要、右图表与表格的布局；小于1000px纵向排列。蓝色主题、高文字对比度、自定义控件、历史活动与实际预测记录规则均保留。测试三列定位、整行点击、下拉联动、右侧内部滚动、切换过渡、自动刷新、历史模式、快速选择、减少动态效果与不同屏宽。
