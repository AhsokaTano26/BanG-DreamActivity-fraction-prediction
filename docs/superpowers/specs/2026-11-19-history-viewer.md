# 历史活动展示

用户询问以前的LIVE数据为何不显示。当前活动选择器只由latest.json中的进行中活动构造，生产曲线库已有104期；真实上线预测账本目前只有活动329。

活动列表改为读取生产库中实际开始时间不早于2024-01-29 13:00且已开始的活动，按实际开始时间倒序显示“编号 · 标题”。默认仍选择当前活动。选择历史活动后，API只读加载该活动所有排名的真实曲线、经核实终分及实际发出的最后预测。没有上线预测时明确显示缺失，不使用当前模型回算并冒充当时预测。

历史模式不按实时观测60分钟规则隐藏历史曲线，不把终分未知的最后观测称为终分。最终观测可能在活动结束后五分钟内上报：保留原上报时间，在API独立返回已核实终分；图表将该终分作为结束状态端点，并注明终点为已核实终分，不伪造实际采样时刻。

全部接口读取runtime/live的隔离生产库和账本，不访问冻结评测答案、不训练、不修改活动归属。当前活动预测与持续反馈流程不变。验收活动目录时间边界、默认当前活动、历史终分与缺失预测、真实历史修订、不同排名、结束后上报时刻、页面切换及刷新选择保持。
