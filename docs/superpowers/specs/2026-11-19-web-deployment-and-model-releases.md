# 网页框架镜像与独立模型发布

追加范围：三篇论文正文 PDF 和二轮补充材料通过 `papers-v*` 独立 Release 发布；原始预测论文首页和作者元数据补为 Tano。仓库只提交源码、文稿和必要编译图表，运行/实验载荷、模型、最终 PDF、编译输出和本地配置加入 `.gitignore`；已有历史工件和本地文件保留。

用户确认：只部署网页，固定现有 CatBoost、特征及 legacy_pair 校正；后续更新来自新增训练数据。采用一个 Docker 镜像 `tano26/bang-dream-activity-fraction-prediction`，不拆模型服务镜像，不新增神经网络插件协议。

镜像只包含服务、网页、固定算法和锁定依赖。`/state` 保存数据库、账本、配置及日志，独立挂载的 `/state/models` 保存不可覆盖的版本权重、当前版本指针及发布包。初次部署通过只读 `/bootstrap` 导入现有数据库和元数据，或通过管理命令导出已有生产状态。所有容器内部路径固定，迁移不依赖开发电脑绝对路径。

框架构建与模型发布使用独立 GitHub Actions 工作流。框架源码和依赖变化构建镜像；模型以 `model-v*` GitHub Release 的压缩包和 SHA-256 发布，模型工作流只校验和发布既有草稿资产，不构建镜像。框架标签使用 `framework-v*`，避免模型标签触发镜像构建。

模型包封装现有完整基础权重、预处理、元数据、原始模型清单及可选已验证误差反馈；保留源码/软件指纹检查，拒绝损坏、路径逃逸、错误配方、旧数据政策及非生产权重。安装事务持有运行锁，保留已有活动 pin，新版本用于下一活动；不清理旧权重。默认部署只加载已发布权重；完整历史已就绪时可显式启用固定配方自动训练，必须防止缺少旧历史时缩小训练集。

网页路由、历史记录和蓝色三列界面复用现有实现。健康检查区分服务存活与模型就绪。部署不安装 macOS 定时任务，不改变当前本机服务和冻结实验。

验收：模型包往返与损坏拒绝、运行锁、期初约束、保留活动 pin、状态迁移、只读网页、镜像排除数据/权重、Compose 校验、容器网页与模型 smoke、项目完整单线程测试，以及可触发的两条发布工作流。
