# 网页控件与桌面布局

用户要求统一包装浏览器控件，桌面改左右布局，并删除页面中的“关闭终端或按 Ctrl+C 停止服务”。

按用户后续指定，将曲线、填充、选中状态和控件强调色统一改为蓝色（#2563eb），保留真实活动横幅。桌面左列放活动选择、活动资料、排名选择、进度与预测摘要；右列放整期图表与全部排名表。宽度小于1000px时改为上下排列。

原生select由共享SelectControl增强为自定义组合框、选项列表、滚动条、选中状态和焦点样式。保留原生select作为隐藏状态源；支持鼠标、方向键、Home/End、回车、空格、Escape、Tab、文字定位与点击外部关闭。后台刷新选项不应重置用户选择或打断打开的菜单。按钮、数据面板、表格和消息采用共享样式。

改动限于网页静态文件及组件脚本白名单路由。预测、自动更新、数据时间守卫继续使用现有实现。API与曲线均使用真实数据。验收包含桌面左右布局、手机无页面溢出、自定义选择器键盘行为、排名表联动、刷新、错误与空状态，以及禁用提示句不再出现。
