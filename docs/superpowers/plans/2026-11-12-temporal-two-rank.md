# T1000 / T2000 完整 V2 训练与评测

**Goal:** 按用户要求，在 V2 全部可用时点上完成两档训练、验证、盲预测和独立评分。

**Architecture:** 从已封存的 temporal_holdout_v2 按排名提取不可变子集；不重新划分活动、不重新抽样、不从 SQLite 重建。新增训练入口沿用已有 CatBoost 特征与超参数，独立评分复用 temporal_evaluate。

**Tech Stack:** 项目 .venv、Python、pandas、CatBoost、joblib。

**Spec:** `docs/superpowers/specs/2026-11-12-temporal-holdout-v2.md` 与本次用户指定的 T1000/T2000 范围。

## 已确定的实验设计

- 保留 198 / 42 / 43 个活动的归属，所有 21 个预设时点及其冻结缺失；没有可用前缀的活动仍保留在分组中，另报告实际参与数。
- 全部训练前缀用于拟合，活动总权重相同。预处理与元数据词表只拟合训练活动。
- 固定候选：当前分数、线性外推、CatBoost 曲线特征、CatBoost 曲线+活动/乐队/卡牌元数据。后两者固定 600 棵、深度 5、学习率 .035、L2 12、种子 42；不进行新超参数搜索。
- 仅由验证集 event-macro MAPE 选择主方法；随后生成全部测试盲预测，不用验证集重训。
- 复制上一轮已封存 V2 预测中对应的两档作为描述性对照（冻结 19 档模型），不由测试表现选择候选。新旧训练排名范围和训练时点同时变化，不能把差值单独归因于某一项。
- 本轮是完整数据集运行，模型范围为上述固定基线与树模型，不声称完成新的神经网络实验。
- 保存数据/代码/环境/模型/预处理/预测指纹，独立评分封存。保留 V1、已有 V2、数据库和旧源码。

## Review Focus

1. 排名过滤不能移动活动或悄悄删除缺失时点；测试逐 case 对照父数据。
2. 训练入口不得解析测试标签；测试在 labels 边界设禁止读取守卫。
