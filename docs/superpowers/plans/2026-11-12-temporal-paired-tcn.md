# V2 双线特征、TCN 与阶段权重对照

**Goal:** 按用户“继续”指令，完成同一冻结两档 V2 上的信息增益、网络结构及阶段权重独立对照。

**Architecture:** 新模块只读取现有盲前缀；同活动、同请求时刻配对，再截断另一档到当前样本实际已观测时刻。缺失配对保留全部案例。复用封存基线与独立时间评分器，全部新结果存新目录。

**Tech Stack:** 项目 .venv，NumPy/pandas/scikit-learn/CatBoost/PyTorch CPU；神经网络测试子进程隔离。

**Spec:** AGENTS.md 的 V2 两档协议；用户接受上一轮提出的三个主对照，阶段权重另行控制。

## 冻结实验设计（任何新测试评分前确定）

- 数据指纹 `1f76f39af8151bba185496411bbcee064b16a4c5aca5c515c1d957a5056fe854`；2229/1548/1514 前缀、原 198/42/43 活动归属不变。
- 原曲线 CatBoost、当前分数、线性外推直接复制上一轮已封存同案例预测，不重训或读取旧评分来选参数。
- 新双线 CatBoost：原自身特征＋对方截至自身观测时刻的特征、两条归一化 33 点曲线及可用标记、同步分数/速度比/差距变化。两条序列共用当前线的已观测时间网格，不向观测区间外插值。
- 对方必须来自同 split、同活动、同请求时刻的盲前缀；截断后不合质量条件或无对应案例则缺失，不搜索之后的案例补全。
- TCN 与双线 CatBoost 读取相同原始特征信息；两条曲线各用 3 层因果卷积分支，宽度 24、膨胀 1/2/4；表格分支宽 32；两个排名输出头。无新增乐队/卡牌特征，避免特征范围再次变化。当前 event_type 和已知时长等原特征保留。
- 两者目标均为线性外推的 log 增长残差，使用活动等权平方误差；最终分数解码沿用既有方式。TCN AdamW lr=.001、weight_decay=.005、dropout=.1、gradient_clip=1、batch=128，最多120轮，至少30轮后允许20轮无改善早停。checkpoint 只由验证 event-macro MAPE 决定。
- 每条卷积分支同时汇总末端状态与全前缀均值，确保早期已观测点也能影响输出。早期输入扰动测试先复现了只用末端状态时受感受野限制的问题，再修复；此更改发生在正式训练前。
- 神经网络种子42/123/2026逐个汇报，并对三个最终分数做算术平均；单种子不进入主方法选择。
- 阶段权重单独控制：使用原单线特征和同一600棵 CatBoost 参数，仅按观测进度 <25%、25%–90%、>=90% 的互斥阶段在活动内部均分总权重。没有某阶段的活动只分配到已有阶段；每个活动总权重仍相等。
- 候选仅为两种简单基线、旧曲线 CatBoost、新双线 CatBoost、阶段权重单线 CatBoost、TCN三种子均值；由验证集选定。无融合系数搜索、无测试后重训。
- 每模型各 split 保存同一 case 集合；模型、预处理、特征缓存、配对审计、权重、源码、版本、逐轮轨迹、盲预测全部封存。独立评分仍使用 temporal_evaluate；另生成新报告。
- 本轮只在用户指定 V2 下比较，不宣称 V1 主标准成绩改善。历史测试曝光和回溯元数据限制继续保留。
