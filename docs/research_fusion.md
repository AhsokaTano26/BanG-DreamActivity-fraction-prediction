# 两档单线/双线稳健融合开发结果

本模块只使用 Temporal V2 两档冻结子集的训练和验证数据。开发目录为
`analysis/research_development/fusion_20261112/`；训练 2229 个前缀、196 个实际
拟合活动，验证 1548 个案例、42 个活动。开发程序没有读取测试前缀或测试答案。
这些结果用于候选选择，不能代替独立封存的最终测试评分。

## 固定候选及结果

所有六个完整配方先写入 `predeclared_manifest.json`，之后才读取验证答案。
下表为 event-macro MAPE，单位 %，越低越好；训练拟合值不代表泛化表现。

| 配方 | 训练拟合 | 验证 |
|---|---:|---:|
| CatBoost RMSE，共享模型，固定融合比例 | 1.901184 | 5.580757 |
| CatBoost RMSE，共享模型，进度融合比例 | 1.899381 | 5.590579 |
| CatBoost MAE，共享模型，进度融合比例 | 1.854288 | 7.087839 |
| CatBoost Huber，共享模型，进度融合比例 | 1.902492 | 5.710756 |
| CatBoost RMSE，分排名模型，进度融合比例 | 1.858963 | **5.213490** |
| ExtraTrees，共享模型，进度融合比例 | 1.188303 | 7.014392 |

本家族按既定验证指标选择 `fusion_cat_rank_progress`。共享 RMSE 的固定融合
与进度融合接近；MAE 和 ExtraTrees 在本轮验证上较差，不能由其较低训练拟合
误差推断改进。这里没有使用验证答案拟合校准器或融合权重，也没有新增网格。

## 训练与融合约束

每个配方独立拟合单线和双线分支，目标为
`log(final/current) + log(observed_progress)`。CatBoost 为 800 轮、深度 5、
学习率 .035、L2=12、种子 42；ExtraTrees 为 500 棵树、叶最少 5 样本、
特征比例 .75、种子 42。每个模型最多使用两个线程。

训练活动具有相同总权重；分排名模型直接切片这一全局权重向量。双线训练为
每个案例生成一份屏蔽另一排名档的副本，原样本与副本分别分配其权重的 .75
和 .25，因此复制不改变案例及活动总权重。插补、类别词表和缺失标志的训练
结构只来自训练前缀。没有历史最终分数或验证/测试完整曲线输入。

固定门控的双线比例为 .5；进度门控在 `<25%`、`25%–90%`、`≥90%` 时分别
为 .65、.45、.25，并乘以 `exp(-peer_age_hours/3)`。双线相对单线的对数修正
截断到 `±log(1.6)`。缺少另一排名档时门控严格为零，最终分数精确回退到该
单线分支；不会删除案例，也不会使用其他时刻的档位补齐。

## 验证和追溯

`tests/test_research_fusion.py` 的五项测试覆盖输入顺序和子集重排、保存重放、
缺档列污染不影响预测、分排名与复制后的活动权重、非训练拟合拒绝、非有限
答案拒绝，以及宽特征表的无碎片化警告构造。

开发运行封存后，将特征表的逐列插入改为一次构造，消除了 Pandas 性能警告。
这一改动没有改变配方、列顺序或数值；六个模型在训练与验证的全部 12 个预测
向量均重放一致（允许 CSV 浮点往返误差）。开发目录仍保存原始运行源码和
其指纹，未覆盖任何旧实验。集成运行应保存当前源码的新指纹。

必须保留两项协议限制：测试队列曾出现在早期探索实验中，不能称为完全未见
的盲测；元数据为当前回溯快照，缺少历史时点存档。
